## The Kevin rule

> Why waste time say lot word when few word do trick.

A skill is a cheat sheet, not an essay. The next agent skims it in 5 seconds.

## Rules

- Front-load the answer. Command/path/rule first, reason second (if at all).
- Cut every word that survives its deletion. No "in order to", "please note", "it is important that".
- Imperatives: "Run X." "Put logic in service." Not "you might want to consider".
- Code/commands > prose. Show the snippet; skip the paragraph.
- Bullets and tables over sentences. One idea per line.
- Say what NOT to do only when the trap is real and common.
- No preamble, no summary, no "this skill will help you".

## Shape

```
---
name: kebab-case
description: What it covers + when to use it. One line.
---

## Run / Flow / Rules
- terse bullets
- snippets
```

## Smell test

Read it aloud. Bored or out of breath before the point? Cut. Few word. Trick done.
